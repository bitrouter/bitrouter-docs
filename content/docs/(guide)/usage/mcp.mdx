[Model Context Protocol](https://modelcontextprotocol.io) connects agents and model requests to tools, resources, and prompts. BitRouter supports MCP in two distinct places:

- The open-source daemon connects and aggregates MCP servers you configure.
- The public Docs MCP server lets any compatible client search BitRouter documentation and model availability.

## Connect upstream MCP servers

Declare third-party servers under `mcp_servers` in [`bitrouter.yaml`](/docs/configuration/config-file). BitRouter exposes each upstream at `/mcp/{server}` and can aggregate participating servers at `/mcp`.

```bash
bro mcp check
bro mcp check context7
```

The gateway can make upstream tools available to compatible model requests. Connection ownership, tool allowlists, and server-side execution remain explicit configuration choices; start with the [MCP gateway guide](/docs/usage/mcp-gateway) before enabling tools in a shared deployment.

## Search the docs over MCP

BitRouter publishes a public [Model Context Protocol](https://modelcontextprotocol.io) server for this documentation. An editor or agent can search the docs, read a page, and check model availability without leaving its current workflow.

- **Endpoint:** `https://bitrouter.ai/mcp`
- **Transport:** Streamable HTTP
- **Authentication:** none

This service answers questions *about* BitRouter. It is separate from the gateway running in your own BitRouter deployment.

## Tools

| Tool | Purpose |
| --- | --- |
| `search_docs(query, limit?, locale?)` | Find relevant documentation and return canonical URLs plus paths for `get_doc` |
| `get_doc(path, locale?)` | Fetch one documentation page as clean Markdown |
| `lookup_model(query)` | Check model availability, pricing, context window, and a configuration snippet |

Clients that support MCP resources can also read the curated index at `bitrouter-docs://llms-index`.

## Add it to a client

Claude Code:

```bash
claude mcp add --transport http bitrouter-docs https://bitrouter.ai/mcp
```

For clients that accept an MCP server configuration:

```json
{
  "mcpServers": {
    "bitrouter-docs": {
      "url": "https://bitrouter.ai/mcp"
    }
  }
}
```

## Operating BitRouter from an agent

BitRouter OSS is not a first-party origin MCP server for local administrative commands. To inspect status, models, routes, or requests, install the [BitRouter Agent Skill](/docs/usage/skills) in a shell-capable host. The Skill selects structured `bro` commands; the host obtains approval and executes them.
