Elastic Inference charges the supplier’s actual settled inference cost plus the Cloud platform fee: **$0.01 per million processed input + output tokens — early access pricing**. The platform fee is counted once per request, including when using Cloud Auto Routing. The buyer’s total price cap includes both charges, calculated using the full output limit for budget checks.
